# Altavia packwiz project (LOCAL, pre-publication)

Pack name "Altavia" is temporary. Status: local only. Nothing is hosted or published, and nothing on the live server or
any client was changed. Hosting (a GitHub repo serving `pack.toml`) is PENDING THE OWNER'S OK.

## Layout
- `flake.nix` - toolchain (packwiz from nixpkgs). Run everything as `nix develop /home/mambuco/Documents/MC/pack -c packwiz ...`
  (the flake needs its files git-tracked: `git add` new top-level files before `nix develop`; `mods/` and `config/` are not read by nix).
- `pack.toml` / `index.toml` - pack metadata (MC 26.3, Fabric loader 0.19.5, version 0.1.0) and the file index (regenerated by `packwiz refresh`).
- `mods/<slug>.pw.toml` - one per mod: Modrinth download URL, sha512, `side`, and `[update.modrinth]` project/version ids.
  168 mods = union of the client instance (`client/profiles/Fabric 26.3/mods`) and `server/mods`, matched by sha1 against
  Modrinth, pinned to the exact installed version.
- `config/` - proposed pack-default CLIENT configs (15 files). See `CONFIG_DEFAULTS.md` for each changed value. Not included: `options.txt`, `servers.dat`, `shaderpacks/`.
- `dist/` - test exports (`.mrpack`), git-ignored.

## Sides
`side` in each `.pw.toml`: `both` (client+server), `client`, `server`. Here: 80 both / 33 client / 55 server.
Set from where the jar is actually installed (both places -> both; only client -> client; only server -> server), cross-checked
with Modrinth client_side/server_side. `.mrpack` export maps it to `env`: both = required/required, client = required/unsupported,
server = unsupported/required (client launchers skip server-only mods). Change a side by editing `side = "..."` and running `packwiz refresh`.

## Everyday commands (prefix: `nix develop /home/mambuco/Documents/MC/pack -c`)
- Add: `packwiz modrinth add <slug-or-url>` (or `--project-id X --version-id Y`); then `packwiz refresh`. Set `side` by hand if needed.
- Update one / all: `packwiz update <name>` / `packwiz update --all`; pin with `packwiz pin <name>`.
- Remove: `packwiz remove <name>` (or delete the toml) then `packwiz refresh`.
- Export client pack: `packwiz modrinth export -o dist/Altavia-<ver>.mrpack`. Bump `version` in `pack.toml` for each release.
- Config defaults: edit files under `config/`, `packwiz refresh`; they ship as `overrides/` in the .mrpack and overwrite on update (decide on
  `preserve = true` in `index.toml` for files players should keep; not configured yet).
